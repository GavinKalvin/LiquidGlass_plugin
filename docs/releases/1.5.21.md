# Liquid Glass v1.5.21

## 更新内容 / Highlights

- 修正原生透景强度方向：数值越大，原生透景贡献越强；150 对应 v1.5.19 最透的 0。旧设置只换算一次，不会在重载后再次反转。
- 新增可单独关闭的「增强透景材质（实验）」：在已有原生玻璃层上使用 macOS under-window 材质，尝试减轻厚雾感；不再靠继续淡出整块透景层加深效果。
- 修复滑块左侧文字重叠：Obsidian 1.13+ 使用系统数值标签，移除重复标签；`150 / 150` 单行显示，旧版保留普通文字标签。
- 原生模块同时保存、回读及恢复 alpha 和材质，并使用新的 `vibrancy_material.node` 文件名避开旧模块缓存。

## 明确适配的插件 / Plugin compatibility

- **[EPUB Reader and Highlighter v0.2.1](https://github.com/okkio-31mon/epub-reader-highlighter)**，作者 **@okkio-31mon**（[作者主页](https://github.com/okkio-31mon)）。感谢其阅读器插件；本项目提供的是针对该插件的液态玻璃兼容层。
- 保留 EPUB 正文、顶部控制栏以及滚动/分页切换控件的适配；不对图片、SVG 或其他媒体元素增加液态玻璃、opacity 或滤镜效果。
- 保留 Gallery Explorer（`gallery-explorer` / `gallery-explorer-view`）主视图与工具栏适配，不改卡片、封面和媒体渲染。
- 保留 Current Note AI 0.1.3 右侧栏兼容。

## 安装与更新 / Installation

从 Assets 下载以下 **4 个文件**，放入 `<vault>/.obsidian/plugins/liquid-glass/`：

- `manifest.json`
- `main.js`
- `styles.css`
- **`vibrancy_material.node`（新版必须使用此原生模块，不是旧的 `vibrancy_alpha.node`）**

保留自己的 `data.json`，然后在第三方插件中关闭并重新开启 Liquid Glass，或重启 Obsidian。无需修改文字、正文或图片透明度。

## 运行范围与验证 / Safety and validation

- CSS 材质依赖 macOS Obsidian 的「半透明窗口」设置。
- 可选原生功能严格限定 **macOS arm64 / Obsidian 1.13.4 或 1.13.7 / Electron 39.8.3**；其他运行时安全停用原生调节。
- 保留主进程验证、唯一全窗玻璃层检查、状态回读、原材质恢复及磁盘崩溃哨兵；不添加滚动监听、轮询、第二层原生玻璃或私有滤镜。
- **19 项自动测试、TypeScript 检查、生产构建、原生模块签名检查及 `git diff --check` 通过。** 自动测试包含模拟生命周期及空窗口句柄保护检查，不等同于现场视觉验证。
- 增强材质仍为实验功能，实际外观受 macOS、主题及窗口状态影响，需重新加载后比较；不满意可单独关闭该开关。不要为加载原生模块关闭 SIP、Gatekeeper 或其他系统安全机制。
